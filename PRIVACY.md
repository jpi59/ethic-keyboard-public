# Privacy notice — Ethic Keyboard

This file is a concise entry point. The applicable, versioned policy is
[PRIVACY_JPI59.md](PRIVACY_JPI59.md), also published as
[docs/privacy.html](docs/privacy.html).

An Android keyboard necessarily receives the text, selection and active-field
information supplied by Android and the app where a person is typing. Ethic
Keyboard processes that information in memory to provide input. It does not
store typed text, transmit it to a server, use accounts, analytics, advertising
or network services. Preferences such as layout, language, theme, size and
vibration are stored locally until changed, cleared through Android settings or
removed by uninstalling the app.

The full policy identifies the `VIBRATE` permission, clipboard boundary,
retention, backup setting and user controls. It is the source of record if this
summary and another document ever differ.
