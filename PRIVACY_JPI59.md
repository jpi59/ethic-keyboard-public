# Política de privacidad — Ethic Keyboard

La versión prevista de Ethic Keyboard funciona localmente y no incluye anuncios, analítica, telemetría, rastreadores ni servicios de red.

Como todo teclado Android, recibe el texto que el usuario decide introducir en las aplicaciones donde lo activa. Ethic Keyboard no debe almacenar, perfilar, enviar ni compartir ese texto. Las preferencias se guardan localmente para configurar el teclado.

El único permiso normal previsto es `VIBRATE`, que se puede desactivar desde la configuración. El servicio de entrada `BIND_INPUT_METHOD` es el mecanismo del sistema para que Android pueda usar un teclado y no se utilizará para conceder acceso a Internet.

Esta política describe el diseño previsto; la publicación queda condicionada a verificar el APK final, el manifiesto, el tráfico de red y una prueba en dispositivo.
